# Palmwine & Pepper — restaurant website

A landing site for a fictional modern Nigerian grill in Lagos: menu with tabs, an illustrated gallery and a table booking form with date and time validation (closed Mondays, last booking 90 minutes before closing).

Built with React, Vite and Tailwind CSS. The restaurant is made up for a portfolio demo and bookings are not sent anywhere.

## Run it locally
```bash
npm install
npm run dev
```
